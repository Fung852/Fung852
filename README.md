# 清风空调清洗 - 预约网站

专业空调清洗服务在线预约网站，适用于空调清洁公司展示服务并接收客户预约。

## 功能特点

- **首页展示**：清晰的主视觉与品牌介绍
- **服务项目**：家用空调清洗、商用空调清洗、保养套餐
- **在线预约**：表单包含姓名、电话、服务类型、日期时段、地址等
- **响应式设计**：支持手机、平板、电脑多端访问
- **表单验证**：手机号格式校验、必填项检查

## 快速开始

### 本地预览

1. 使用任意静态服务器运行，例如：

```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js (需先安装: npm i -g serve)
serve .
```

2. 在浏览器打开 `http://localhost:8000`

### 直接打开

也可直接用浏览器打开 `index.html` 文件（部分功能可能受 CORS 限制）。

## 后续扩展建议

1. **后端对接**：在 `js/main.js` 的提交逻辑中接入真实 API，将预约数据保存到数据库
2. **管理后台**：开发预约管理界面，便于查看和安排工单
3. **短信/邮件通知**：预约成功后自动发送确认信息
4. **支付功能**：集成在线支付（如微信支付、支付宝）

## 自定义配置

- **公司名称**：在 `index.html` 中搜索「清风空调清洗」替换为您的品牌名
- **联系方式**：修改「联系我们」区块中的电话、微信等信息
- **服务价格**：在服务卡片中调整 `price` 显示内容
- **配色**：在 `css/styles.css` 的 `:root` 中修改 `--primary` 等变量
